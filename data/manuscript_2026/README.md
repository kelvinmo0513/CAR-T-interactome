# External input manifest and aggregate regression expectations

`input_manifest.json` lists the exact October 7 inputs, their relative paths in
the authors' archive, destination names for staging, sizes and SHA-256 hashes.
The `analysis` group is required for the clinical replay; the `reference` group
adds the annotated object, reference matrices and recorded GUI service outputs.
Obtain files as described in [PROVENANCE.md](../../docs/manuscript_2026/PROVENANCE.md).
Do not place them in this public directory.

`expected_results.json` contains aggregate cohort models, the two selected pools
and four KM summaries. The chemotherapy reference `CI_low` and `CI_high` fields
are on the historical log-HR scale; CAR-T pool limits are odds ratios. The
verifier handles that distinction explicitly. Curve and risk-table expectations
are hashes of sorted aggregate tables, rounded to nine decimal places; their
individual follow-up times are not distributed here.

Expected values are used only after fitting and during verification. Neither
analysis nor rendering reads this file to populate a result or plot. The renderer
uses the numerical tables generated by the current run.
